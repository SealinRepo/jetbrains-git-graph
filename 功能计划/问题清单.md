# Current Branch面板优化
- 分支名称粗体显示逻辑调整: 只对提交列表中当前活跃(选中)的分支进行粗体显示，而不是点到就变成粗体

# 兼容Jetbrains idea变更列表
如果当前项目下存在.idea目录, 优先读取idea的change list配置, 保持与IDEA的变更列表和列表中的文件显示一致

# 代码对比操作优化
从代码对比窗口中跳转到源码文件是不可编辑状态，改为跳转操作默认是转到可编辑状态的最新文件。

# 插件面板行为
插件启动时, 不需要勾选任何变更列表和文件, 如果之前有选中也要在启动后取消勾选状态,搁置的提交恢复到变更列表后也不需要勾选, 避免误提交.
